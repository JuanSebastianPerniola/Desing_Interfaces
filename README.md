# Desing_Interfaces

Repository for Interface Design & Programming Environments Exercises

## Description

This repository contains a collection of exercises, mini-projects and code samples related to interface design and programming environments.
It is structured to showcase various tasks you have completed (for example in C#, Visual Basic, HTML, CSS) under the theme of designing interfaces and working on application development.

## Contents

Here is an overview of the typical folders and files included:

* `CalculaMna/`, `SueldoCalculaor/`, `WebApplication1/`, etc. — Each folder corresponds to a specific exercise or class task, with source code and project files.
* `CodeWarsShit/` — Solutions of programming challenges (e.g., from CodeWars).
* `README.md` — This documentation file.
* Possibly `.zip` files with archived projects or solutions.
* Misc assets or supporting files.

## How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/JuanSebastianPerniola/Desing_Interfaces.git
   ```
2. Navigate into the folder of the project you want to open.
3. Open the project in the appropriate IDE (e.g., Visual Studio for C# / VB.NET, or any editor for web files).
4. Run or compile the project to explore its functionality.
5. If you want to add or modify an exercise:

   * Create a new folder with a clear name (e.g., `MyNewInterfaceExercise/`).
   * Add your source files, resources, and perhaps a short README inside.
   * Commit with a meaningful message like “Added new interface design exercise in C#”.
   * Push your changes.

## Best Practices

* Use descriptive folder and file names (e.g., `Task1_LoginAndSearch`, `Activity_SueldoCalculator`).
* Keep each exercise self-contained (folder includes source, resources, and maybe instructions).
* Document your code when necessary (especially if using multiple technologies).
* Commit often with meaningful messages — e.g., “Task1 – login UI implemented”.
* Before uploading, verify the project runs in its target environment.

## Technology Stack

* C# and/or Visual Basic .NET (for Windows application exercises)
* HTML / CSS (for web application part)
* JavaScript (if any dynamic web parts)
* IDEs: Visual Studio, etc.
* Version control: Git & GitHub
